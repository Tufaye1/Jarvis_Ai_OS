1 · Phone on the counter

Fill before scanning
  1. Connect the phone to this Mac with a USB-C data cable.
  2. Unlock the phone. Tap Trust and enter its passcode. Shops usually know it, or it is at the Hello screen. Finish setup with Wi-Fi first.
  3. Press Enter or the button. A scan takes about 5–20 seconds.

2 · Automatic results

CheckReadingResult

"Unknown" means the phone refused that read. It is not a pass, so do that check by hand.

3 · Battery drain test

Run it only on your final 1–2 phones
Read this first. The phone charges while it's plugged into the Mac, so drain can't be measured while it's connected. The tool reads the level, you unplug and run the same workload for a fixed time, then plug back in and it reads again. The level only moves in whole 1% steps, so a 5-minute test is mostly noise. 10 minutes is the shortest that means anything.

4 · Hands-on checks

The Mac can't test cameras, speakers, buttons or the body. Run these on the phone and mark each one. Deal-breakers rule the phone out.
